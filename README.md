# HTML, CSS et JavaScript pour les SCORM Moodle

Fichiers communs (éditeur à trois onglets, aperçu isolé, console, messages d'erreur en français,
vérification automatique) chargés par les paquets SCORM des séries d'exercices, depuis :

    https://scormcdg.github.io/javascript/script/v1/

Voir `script/v1/LISEZMOI.md` pour le détail des fichiers et le format des séries.
